# Signaux d'interdiction et d'avertissement ISO 7010

Bibliothèque commune des applis Suivi, gérée par SuiviPDP : `https://zbpbasv.cluster121.hosting.ovh.net/suivipdp/pictos/`.

- `P0xx.svg` (interdiction, cercle rouge) et `W0xx.svg` (avertissement, triangle jaune) pour l'écran ; `.png` 256 px pour les exports PDF / Word — 48 signaux.
- `catalogue.json` : code, type, nom en français, famille, `ancienId` = ancienne interdiction dessinée de SuiviPDP remplacée par le signal.
- `index.html` : visualiseur (recherche, filtre « Interdictions seulement », `?code=P002`, `?embed=1`).
- Autres bibliothèques : EPI / obligations (ISO 7010 M) dans SuiviEPI `../suiviepi/pictos/` ; dangers des produits (CLP) dans SuiviChimique `../suivichimique/pictos/`.
